# Meteo 0.9.1

- Keep Android meteograms visible after rotation and give charts more space in
  landscape. Move the visible interval, parameter picker and export actions to
  the mobile header.
- Fix place suggestions with predictive keyboards, including Samsung Keyboard.
- Add a Current location mode that follows the device while the app is active.
  Show located points on the map and resolve their place names automatically.
- Add system, light and dark themes, with consistent colors throughout mobile
  settings and place forms.
- Show progress while locating the device, resolving place names and refreshing
  forecasts, including when cached data are already visible.
- Improve touch panning by reusing chart labels and drawing visible charts once
  per frame.
- Keep the Plasma popup size stable when chart sections are collapsed.
- Add AUR source package preparation and metadata for an F-Droid packaging
  request. F-Droid source-build integration for Qt/KDE dependencies is still
  pending.

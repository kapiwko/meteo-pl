# Meteo 0.9.3

- Keep saved Plasma locations selected after switching from the device's current
  position. Preserve widget place selections when coordinates are edited or reused.
- Keep location acquisition active while permission is pending and resume it when
  the app returns to the foreground. Open Android's permission dialog after the
  initiating UI callback has finished.
- Preserve chart fills around repeated polygon corners and align precipitation
  fills with their lines, markers and native forecast intervals.
- Keep negative and zero values visible when using horizontal segments. Give
  numeric wind direction its own angular axis and break lines at direction wraps.
- Offer only complete color palettes compatible with the selected series, keep
  legend samples consistent with rendered styles and preserve imported color alpha.
- Limit dashed-line geometry and clip off-screen segments before tessellation to
  prevent unusually fine imported dash patterns from freezing the interface.
- Move charts by stable identity and make profile edits and undo atomic. Reject
  undo when another process has changed an affected profile.
- Include overlapping gust intervals in daily summaries and match precipitation
  categories to their actual intervals. Mark uncertain interval-based summaries.
- Clear pending map loads when returning to the image already displayed, so map
  animation can continue without a stuck loading indicator.
- Discard older cached JSON after a successful response that cannot be reused.
  Respect HTTP cache expiry and update cache access timestamps on Windows.
- Keep cache clearing within physical cache directories, skipping symbolic links
  and Windows junctions, including a redirected cache root.
- Test chart export cancellation without leaving partial output files.
- Separate profile and place rules, chart preparation, network transport and
  storage from UI adapters. Share location acquisition and map-frame transitions
  between the application and Plasma widget, and keep KRunner independent of the
  chart and UI libraries.
- Expand CPU/GPU comparison coverage, retain native renderer artifacts in CI and
  add Windows filesystem and installer checks. Exercise setup, permissions,
  rotation, navigation, updates and document import/export against the built APK.
- Document the published AUR package and its maintainer identity.

# Meteo 0.9.0

Meteo brings ICM forecasts to a Qt/Kirigami application for Linux and Android,
with a Plasma 6 widget for the desktop. This release is intended for broader
testing before version 1.0.

- Interactive meteograms with configurable JSON profiles, mixed chart series,
  CPU/GPU rendering, legends and detailed parameter readings.
- Forecasts by hour and day, interactive weather maps, animated thematic maps,
  synoptic commentary and articles.
- Separate saved-place management and an explicit first-launch setup.
- Independent profile editing, import/export, scoped undo and validated axes.
- PNG chart export, parameter export and native file selection.
- A compact Plasma popup with collapsible charts and the full application one
  click away.
- Android touch navigation, chart gestures and a default 72-hour interval.
- Bounded caches for forecasts, map imagery, articles and place queries.
- English and Polish interfaces, improved responsive settings and a gallery of
  real screenshots in the README.

## Downloads

Linux packages are provided separately for current Arch Linux, Debian 13,
Ubuntu 26.04 and Fedora 44. They use system Qt/KDE libraries. The Plasma widget
requires Plasma 6. The Android APK targets arm64 devices and carries the
persistent application release signature. Windows and macOS are outside this
release's downloadable package set.

## Verify the release

The annotated Git tag and `SHA256SUMS.asc` are signed with Kamil Piwowarski's
GPG key. Check the full fingerprint through a trusted channel before importing
`SIGNING-KEY.asc`, then verify the manifest and downloaded files:

```sh
gpg --import SIGNING-KEY.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check SHA256SUMS
```

The signed manifest covers packages, source archives, per-platform build
reports and `BUILD-PROVENANCE.json`, which identifies the source commit, CI
runs and Android certificate.

# Meteo 0.9.5

- AUR builds no longer compile or run the test suite by default, avoiding test
  dependencies and reducing build time for normal installations.
- Keep full tests available with
  `METEO_AUR_TESTS=1 makepkg --cleanbuild --syncdeps --check`. Release CI continues
  to run the full test suite and verify package installation before publication.
- Preserve source checksums and the maintainer's signature verification for
  every AUR build.

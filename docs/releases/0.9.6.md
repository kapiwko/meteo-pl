# Meteo 0.9.6

- Show `0°C` instead of `-0°C` when a small negative temperature rounds to zero.
  The fix covers forecast headers, hourly and daily forecasts, chart readings
  and the Plasma widget.
- Use consistent localized rounding for forecast values and chart axis labels.
  Negative values remain visible whenever the displayed precision distinguishes
  them from zero.
- Preserve the original forecast values for plotting and numeric exports.

# Meteo 0.9.2

- Add an Android setup wizard with a welcome screen, location mode, forecast
  model, chart profile, color theme and wind units. Explain saved places and
  request location access after confirmation. Remember the selected location mode.
- Open place search when location access is denied or a position is unavailable.
  Bound location requests even when a provider never reports a timeout.
- Support incomplete place names in Poland and make search results clearly
  selectable, with a location icon, selection action and keyboard dismissal.
- Keep both chart axes fixed for the complete forecast while panning or zooming.
- Save PNG charts, CSV readings and profile files through Android's system file
  picker, and import profiles from Android documents.
- Keep the location icon visible in compact mobile headers and correct Polish
  weather parameter labels.
